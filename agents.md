# Agent Instructions

1. Commit all completed work.
2. Update `status.md` whenever work is completed.
3. When developing a feature, add and run only the tests necessary to verify that feature; avoid unrelated or full-suite checks unless warranted by the change.
4. Do not run automated native-app tests. Verify native app behavior manually only when explicitly requested; use focused unit/type/build checks for code changes.
5. Prefer aggressive, minimal implementation. Run only necessary focused checks; do not run full suites or unrelated checks unless required to resolve a concrete failure.
