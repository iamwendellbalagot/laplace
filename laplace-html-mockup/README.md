# Laplace — Static Desktop UI Concept

A multi-screen, offline-first **HTML/CSS/JavaScript design prototype** for Laplace, inspired by the supplied implementation plan. Open `index.html` or the **single-file** `laplace-standalone.html` in a modern browser. No dependencies, package manager, network requests, or build process.

## Views

1. Overview — the project working state and current activity.
2. Editor — code-first workspace with explorer, editable sample text, context, and terminal mockup.
3. Changes — durable engineering changes and their lifecycle.
4. Review — candidate diff, acceptance criteria, evidence, approval and integration concepts.
5. Context — architectural/system relationships with source traceability.
6. Verify — source-specific check/evidence ledger and freshness semantics.
7. Rook — contextual Plan/Build delegation and permission treatment.
8. Tools — Skills and MCP connection/capability management.
9. Settings — display and workflow preferences.

## Interactions

Navigate from the left rail or press **Ctrl/Cmd+K** for the command palette. Other interactive elements include the explorer files, editor view/edit mode, in-memory save, terminal show/hide, Change review, verification filters, context navigation, skills/MCP switches, tabs, and theme/spacing preferences. The UI is responsive for narrower windows.

All project data, code, integration states, execution logs, and tool statuses are **illustrative sample content**. There is no actual file-system, Git, Rook, MCP, testing, or terminal backend. The editor saves sample edits only in page memory. Editing a sample Change candidate marks its sample evidence stale until a real check would be rerun. Nothing is sent or executed.

## Design

Dark graphite canvas, warm off-white typography, subtle brass highlights, editorial serif titles, quiet grid lines, monospaced engineering data, restrained information density, and a custom orbit/constructivist mark. No external images or fonts are required.
